# 🔗 Stripe Webhook Setup Guide

This guide explains how to set up separate webhook endpoints for development and production environments, ensuring that Vercel deployments work independently of the Stripe CLI.

## 🎯 Problem Solved

- **Issue**: Vercel payments fail when Stripe CLI is not running
- **Root Cause**: Single webhook endpoint shared between development and production
- **Solution**: Separate webhook endpoints for each environment

## 🏗️ Architecture Overview

```
Development Environment:
Stripe CLI → localhost:3000/api/webhooks/stripe

Production Environment:
Stripe Dashboard → https://structra-two.vercel.app/api/webhooks/stripe
```

## 🔧 Setup Instructions

### 1. Development Environment (Already Configured)

✅ **Current Setup:**
- Stripe CLI forwards webhooks to `localhost:3000/api/webhooks/stripe`
- Uses `STRIPE_WEBHOOK_SECRET` environment variable
- Webhook secret is dynamically generated by Stripe CLI

**To start development:**
```bash
# Terminal 1: Start development server
npm run dev

# Terminal 2: Start Stripe CLI webhook forwarding
./stripe-cli/stripe.exe listen --forward-to localhost:3000/api/webhooks/stripe
```

### 2. Production Environment Setup

#### Step 1: Create Production Webhook Endpoint

1. **Go to Stripe Dashboard:**
   - Navigate to [Stripe Dashboard](https://dashboard.stripe.com)
   - Go to **Developers** → **Webhooks**

2. **Add New Endpoint:**
   - Click **"Add endpoint"**
   - **Endpoint URL:** `https://structra-two.vercel.app/api/webhooks/stripe`
   - **Description:** "Structra Production Webhooks"

3. **Select Events:**
   Add these events (same as development):
   - `checkout.session.completed`
   - `payment_intent.succeeded`
   - `payment_intent.payment_failed`
   - `invoice.payment_succeeded`
   - `invoice.payment_failed`
   - `customer.subscription.created`
   - `customer.subscription.updated`
   - `customer.subscription.deleted`

4. **Save and Get Webhook Secret:**
   - After creating, click on the webhook endpoint
   - Click **"Reveal"** next to **Signing secret**
   - Copy the secret (starts with `whsec_`)

#### Step 2: Configure Vercel Environment Variables

1. **Go to Vercel Dashboard:**
   - Navigate to your Structra project
   - Go to **Settings** → **Environment Variables**

2. **Add Production Webhook Secret:**
   - **Name:** `STRIPE_WEBHOOK_SECRET_PRODUCTION`
   - **Value:** The webhook secret from Step 1
   - **Environment:** Production

3. **Redeploy:**
   - Trigger a new deployment to apply the environment variable

## 🔍 How It Works

The webhook handler automatically detects the environment:

```typescript
// Determine which webhook secret to use based on environment
const isProduction = process.env.NODE_ENV === 'production' || process.env.VERCEL
const webhookSecret = isProduction 
  ? process.env.STRIPE_WEBHOOK_SECRET_PRODUCTION 
  : process.env.STRIPE_WEBHOOK_SECRET
```

**Development:**
- Uses `STRIPE_WEBHOOK_SECRET` (from Stripe CLI)
- Requires Stripe CLI to be running

**Production:**
- Uses `STRIPE_WEBHOOK_SECRET_PRODUCTION` (from Stripe Dashboard)
- Works independently without Stripe CLI

3. **Monitor webhook delivery in Stripe Dashboard**
4. **Set up webhook endpoint monitoring/alerting for production**

## 🔧 Troubleshooting

### Development Issues
- **Webhook signature verification failed:** Restart Stripe CLI to get new secret
- **Webhook not received:** Check if Stripe CLI is running and forwarding to correct port

### Production Issues
- **Webhook signature verification failed:** Verify `STRIPE_WEBHOOK_SECRET_PRODUCTION` is set correctly in Vercel
- **Webhook endpoint not found:** Ensure Vercel deployment is successful and endpoint URL is correct
- **Webhook timeout:** Check Vercel function logs for errors
